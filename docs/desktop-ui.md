# 桌面 UI 使用说明

Tauri 2 和 Electron 使用同一套前端，通过 `clevod` 的 D-Bus 接口读取和保存设置。
用登录用户启动 UI，不要用 `sudo`。安装见 [install.md](install.md)，两种壳的区别
见 [electron.md](electron.md)。

```bash
clevo-cc-ui            # Tauri
clevo-cc-ui-electron   # Electron
```

## 页面

| 页面 | 内容 |
|---|---|
| 概览 | 风扇、温度、性能模式、CPU/GPU 和内存等资源占用 |
| 风扇 | 风扇模式与自定义曲线；`customize` 对应 CLI/固件的 `custom` |
| RGB 灯效 | 根据后端提供静态颜色、亮度、关闭及分区控制；本机 RGB15 是单区 |
| 电源与电池 | 左侧为外接电源提示和桌面电源模式，右侧为电池状态与充电阈值 |

缺失读数保持未知；服务或硬件读取失败时显示错误。风扇读取失败不阻止电源页面读取。
风扇曲线的「还原默认」使用 daemon 捕获的本机真实出厂曲线，尚未捕获时不可使用。

## 电源与电池

页面每五秒读取一次，左侧刷新按钮可以立即更新。电池卡片显示电量、充电状态、
容量健康度和循环次数；缺失字段不会显示成零。

标准阈值后端提供百分比输入，可能只支持停止阈值。原生 FlexiCharger 提供
「充电阈值控制」开关和固件允许的开始/停止档位。修改后点击「保存」触发
PolicyKit 授权；未保存的开关或档位变化不会写入硬件。关闭原生控制会保留窗口值。
未提供接口或无法读取当前阈值时，相关控件禁用并显示原因。

开始值必须低于停止值。停止阈值不会主动降低已有电量；设置 80% 后仍显示 99%
并不表示失败。KDE 的「完全充满」和本页的「未充电」也可能同时成立，具体状态
解释及真机测试见 [power.md](power.md)。

桌面模式只操作属于 `clevo-cc` 的 `platform_profile` provider；其他驱动的模式
不会被当作本项目接口。KDE 自带电源方案选择还需要可用的桌面电源服务，驱动节点
存在不代表桌面服务已安装或运行。

## 设置与托盘

设置包含外观、显示、应用程序及兼容性选项。显示设置调整应用窗口与缩放，不改变
显示器分辨率。关闭主窗口后 UI 留在托盘，可从菜单重新打开、切换性能模式或退出。

设置中的登录自启动属于当前用户，登录时只驻留托盘；daemon 的 systemd 启动
与 UI 自启动分别配置。切换 Tauri/Electron 或移动程序后，在新程序内关闭并重新
开启自启动以更新路径。操作与测试见 [autostart.md](autostart.md)。

遇到授权失败、daemon 无法连接或接口缺失时，先运行：

```bash
clevo-cc --transport dbus doctor
clevo-cc --transport dbus power status --json
```

诊断范围和退出码见 [doctor.md](doctor.md)。
